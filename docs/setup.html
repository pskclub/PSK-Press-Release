เริ่มต้น

หน้าแรก ติดตั้งและอัปเดต เชื่อมเบราว์เซอร์และบัญชี ตั้งค่าครั้งแรก คลิปแรกใน 10 นาที

สร้างงาน

พื้นฐานหน้าสร้างงาน การตกแต่งและส่งออก คลิปขายสินค้า คลิป AI ด้วย Google Flow เรื่องเล่า AI ข่าว พอดแคสต์ รีมิกซ์ & ขัดเกลา ชุดภาพสินค้า ตัดต่อเอง

งาน

คลัง

สินค้า ตัวละคร เสียง & เพลง ชุดแบรนด์ คลังพรีเซ็ตชุมชนและแชร์การตั้งค่า

ระบบ

เริ่มต้น

ตั้งค่าครั้งแรก

เลือกว่าจะใช้ AI ตัวไหนเขียนบท วาดภาพ พากย์เสียง ถอดเสียง และทำคลิป — ใช้ผ่านเว็บด้วยบัญชี Google ที่มีอยู่ หรือใช้คีย์ API ก็ได้

ตัวช่วยตั้งค่าครั้งแรกเปิดแอปครั้งแรกจะมีตัวช่วยพาเลือกวิธีใช้ AI (คีย์ API / Gemini ผ่านเว็บ / AI ในเครื่อง) เชื่อมส่วนขยาย เลือกเสียงและสไตล์ซับ แล้วลองสร้างงานแรกแบบ 1 ฉาก ข้ามขั้นไหนก็ได้ เปิดอีกครั้งได้ที่ ตั้งค่า → เกี่ยวกับ → เปิดตัวช่วยตั้งค่าอีกครั้ง

ไปที่ ตั้งค่า → โมเดล AI แต่ละงานเลือกผู้ให้บริการแยกกันได้ แก้แล้วอย่าลืมกด บันทึก มุมขวาบน ถ้าออกจากหน้าโดยยังไม่บันทึก แอปจะถามก่อน

สองทางเลือก: ผ่านเว็บ หรือ ผ่าน API

ผ่านเว็บ (ส่วนขยาย)ผ่าน API (คีย์)
ต้องมีอะไรบัญชีที่ล็อกอินใน Chrome + ส่วนขยายที่เชื่อมแล้วคีย์ API จากผู้ให้บริการ
ค่าใช้จ่ายตามแพ็กเกจบัญชีเว็บของคุณจ่ายตามการใช้งานกับผู้ให้บริการ
ความเร็ว / ความเสถียรช้ากว่า ขึ้นกับโควตาของเว็บ ทำทีละคำขอต่อเว็บเร็ว เสถียรกว่า
ตัวเลือกในแอปGemini (ผ่านเว็บ · ส่วนขยาย), ChatGPT (ผ่านเว็บ · ส่วนขยาย), Google Flow (ผ่านส่วนขยาย)Google Gemini (API), OpenAI (API), Veo (API), ElevenLabs
ข้อควรรู้เรื่องการใช้ผ่านเว็บ การสั่งงานผ่านเว็บอัตโนมัติอาจขัดข้อกำหนดของผู้ให้บริการ และขึ้นกับโควตาบัญชี ถ้าต้องการความเสถียรให้ใช้ API key แอปไม่แก้ captcha และไม่สลับบัญชีหนีโควตา ถ้าเว็บขอให้ยืนยันตัวตนหรือแจ้งว่าโควตาหมด งานจะหยุดรอคุณ

ตั้งค่าที่แนะนำสำหรับเริ่มต้น (ไม่ต้องมีคีย์)

ส่วนในหน้าโมเดล AIเลือก
เขียนบท (LLM) → ผู้ให้บริการGemini (ผ่านเว็บ · ส่วนขยาย)
สร้างภาพ → ผู้ให้บริการGemini (ผ่านเว็บ · ส่วนขยาย)
วิดีโอ AI → ผู้ให้บริการGoogle Flow (ผ่านส่วนขยาย)
เสียงพากย์เริ่มต้นต้องใช้คีย์ (ดูด้านล่าง) — ถ้าใช้แบบ “คนในคลิปพูดเอง” ในคลิป AI ไม่ต้องใช้เสียงพากย์

คีย์ API

ที่ ตั้งค่า → คีย์ API คีย์เก็บในระบบของ Windows ไม่ได้เขียนลงไฟล์ และส่งตรงถึงผู้ให้บริการเท่านั้น

  1. กด ขอคีย์ ในแถวของผู้ให้บริการ เพื่อไปหน้าสร้างคีย์
  2. วางคีย์ในช่อง แล้วกด บันทึก แอปจะทดสอบคีย์ทันที
  3. ป้ายเปลี่ยนเป็น ตั้งแล้ว ปุ่ม ตรวจ ใช้ทดสอบซ้ำ ปุ่ม ลบ ใช้ลบคีย์ (มีถามยืนยัน)
คีย์ใช้ทำอะไร
Google AI (Gemini)เขียนบท สร้างภาพ เสียงพากย์ Gemini และวิดีโอ Veo ผ่าน API
OpenAI (GPT / Whisper)เขียนบท สร้างภาพ เสียงพากย์ และ ถอดเสียงเป็นซับ (Whisper) — จำเป็นสำหรับ ขัดเกลาคลิปพูด และซับที่ถอดจากเสียงในคลิป
ElevenLabs (TTS)เสียงพากย์คุณภาพสูง โคลนเสียง และสร้างเอฟเฟกต์เสียง

ตั้งค่าแต่ละส่วนในหน้าโมเดล AI

เขียนบท (LLM) และ สร้างภาพ

  • ผู้ให้บริการ — Google Gemini (API) / OpenAI (API) / ChatGPT (ผ่านเว็บ) / Gemini (ผ่านเว็บ) · เขียนบทเลือก Ollama (AI ในเครื่อง · ไม่ต้องใช้คีย์) ได้ด้วย
  • โมเดล — ถ้าใช้ API รายชื่อโมเดลดึงสดจากบัญชีของคุณ ถ้าใช้ผ่านเว็บ จะใช้โมเดลที่ตั้งไว้ในหน้าเว็บ
  • + ใช้ Base URL อื่น (proxy) — สำหรับผู้ที่ใช้ proxy เท่านั้น ปกติไม่ต้องแตะ

Ollama — AI เขียนบทในเครื่อง

เขียนบทได้ฟรีโดยไม่ต้องมีคีย์ และบทไม่ออกนอกเครื่อง ติดตั้ง Ollama จาก ollama.com แล้วดาวน์โหลดโมเดล เช่น ollama pull qwen2.5 หรือ ollama pull llama3.1 (เลือกโมเดลที่ภาษาไทยดี) จากนั้นเลือก Ollama ในเขียนบท กด ตรวจการเชื่อมต่อ แล้วเลือกโมเดลจากรายการ เปิดโปรแกรม Ollama ไว้ระหว่างสร้างงาน ภาพและเสียงยังใช้ผู้ให้บริการอื่น

เสียงพากย์เริ่มต้น

เลือก ผู้ให้บริการ (ElevenLabs / Google Gemini / OpenAI) โมเดล และ เสียง ใช้เป็นค่าเริ่มต้นของทุกงาน แต่ละงานเปลี่ยนเสียงเองได้ในส่วน การตกแต่ง ฟังตัวอย่างเสียงได้ที่ เสียง & เพลง

ถอดเสียง (ซับจากคลิปพูด)

เลือก โมเดล และ ภาษาเริ่มต้น (ค่าเริ่มต้นคือ “ตรวจอัตโนมัติ”) ใช้คีย์ OpenAI

วิดีโอ AI

  • ปิด — ไม่ทำคลิป AI ใช้ภาพนิ่งขยับช้า ๆ แทน
  • Google Flow (ผ่านส่วนขยาย) — ใช้เครดิต Flow ของบัญชี Google ใน Chrome ดู คลิป AI ด้วย Google Flow
  • Veo (API) — ใช้คีย์ Google AI จ่ายตามการใช้งาน

เมื่อเลือก Google Flow จะมีสวิตช์ ยืนยันสิทธิ์ใช้รูปภาพใน Google Flow ให้อัตโนมัติ เมื่อคุณแนบรูป Flow จะถามทุกครั้งว่าคุณมีสิทธิ์ใช้รูปนั้นไหม ถ้าเปิดสวิตช์นี้ แอปจะกดยืนยันให้เอง แอปจะถามก่อนเปิด (ปุ่ม ฉันมีสิทธิ์ใช้ทุกรูป — เปิด) ให้เปิดเฉพาะเมื่อรูปสินค้าและรูปคนทุกรูปที่ใช้ คุณมีสิทธิ์ใช้จริง

ตรวจความพร้อม

กลับไปหน้า ภาพรวม กล่อง ตั้งค่าให้พร้อมก่อนสร้าง ทุกข้อควรขึ้น “พร้อมแล้ว” และในหน้าสร้างงานทุกหน้า การ์ด พร้อมสร้าง ด้านขวาจะบอกสิ่งที่ยังขาด เช่น:

  • “คีย์ … ” → ลิงก์ ใส่คีย์
  • “… ต้องเชื่อมส่วนขยายในเบราว์เซอร์ก่อน” → ไปเชื่อมต่อ
  • “ล็อกอิน … ใน Chrome” → ดูบัญชีที่ล็อกอิน
  • “FFmpeg (ตัวประกอบวิดีโอ) ใช้ไม่ได้” → ตรวจเครื่องมือ

ระหว่างที่ยังตั้งค่าไม่ครบ ปุ่ม สร้างเลย จะกดไม่ได้ แต่ยังกด เก็บเข้าคิวไว้ก่อน ได้ แล้วค่อยเริ่มคิวเมื่อตั้งค่าครบ
