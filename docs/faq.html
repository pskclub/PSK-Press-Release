⭳ ดาวน์โหลด

เริ่มต้น

หน้าแรก ติดตั้งและอัปเดต เชื่อมเบราว์เซอร์และบัญชี ตั้งค่าครั้งแรก คลิปแรกใน 10 นาที

สร้างงาน

พื้นฐานหน้าสร้างงาน การตกแต่งและส่งออก คลิปขายสินค้า คลิป AI ด้วย Google Flow เรื่องเล่า AI ข่าว พอดแคสต์ รีมิกซ์ & ขัดเกลา ชุดภาพสินค้า ตัดต่อเอง

งาน

ตรวจฉาก (storyboard) คิวงานและบันทึก ผลงาน โพสต์

คลัง

สินค้า ตัวละคร เสียง & เพลง ชุดแบรนด์ คลังพรีเซ็ตชุมชนและแชร์การตั้งค่า

ระบบ

ตั้งค่าทั้งหมด พรอมต์ระบบ แก้ปัญหาที่พบบ่อย แจ้งปัญหาให้ผู้พัฒนา คำถามที่พบบ่อย ใช้อย่างรับผิดชอบ

ระบบ

คำถามที่พบบ่อย

ค่าใช้จ่าย ความเป็นส่วนตัว การใช้งานโดยไม่มีคีย์ เครดิต Flow และอื่น ๆ

ต้องจ่ายเงินไหม

ตัวแอปไม่มีค่าใช้จ่ายและไม่มีระบบสมาชิก ค่าใช้จ่ายมาจากบริการ AI ที่คุณเลือกใช้เอง:

  • ผ่านเว็บ — ใช้บัญชี Gemini / ChatGPT / Google Flow ของคุณ ตามแพ็กเกจและโควตาของบัญชีนั้น (Flow ใช้เครดิต)
  • ผ่าน API — จ่ายตามการใช้งานกับ Google, OpenAI หรือ ElevenLabs โดยตรง

ใช้ได้โดยไม่มีคีย์ API ไหม

ได้ ถ้าตั้งเขียนบทและสร้างภาพเป็น Gemini (ผ่านเว็บ) และวิดีโอเป็น Google Flow แต่เสียงพากย์ AI ยังต้องใช้คีย์ (ElevenLabs, Gemini หรือ OpenAI) ถ้าไม่มีคีย์เลย ให้ใช้คลิป AI แบบ “คนในคลิปพูดเอง” หรือโหมดแผ่นสตอรี่บอร์ด ซึ่งเสียงมาจากคลิปเอง

ข้อมูลของฉันถูกส่งไปที่ไหนบ้าง

ไม่มีเซิร์ฟเวอร์ของแอป ข้อมูลส่งตรงไปยังบริการที่คุณเลือกเท่านั้น:

  • บท รูป และคำสั่ง → ผู้ให้บริการ AI ที่คุณตั้งไว้
  • คลิป → แพลตฟอร์มที่คุณสั่งโพสต์

แอปไม่ส่งข้อมูลการใช้งานออกไป และเก็บคีย์ไว้ในระบบของ Windows

คลิปหนึ่งใช้เครดิต Flow เท่าไร

ขึ้นกับโมเดล จากการทดสอบ: Omni 1.1 Flash ประมาณ 12 เครดิต/คลิป, Veo 3.1 - Fast ประมาณ 20 เครดิต/คลิป คลิปขายสินค้า 15 วินาทีใช้ 2 คลิป ดูตัวเลขจริงของแต่ละงานได้ในบันทึกของงาน Flow ไม่หักเครดิตเมื่อปฏิเสธคำขอ

ทำไมใช้เวลานาน

  • การทำผ่านเว็บ — ทำทีละคำขอ วางบทใช้ประมาณ 30 วินาที – 2 นาที วาดภาพประมาณ 30–60 วินาทีต่อภาพ ทำคลิปประมาณ 1–3 นาทีต่อคลิป
  • เมื่อถูกปฏิเสธ — แอปรอก่อนลองใหม่ (สูงสุดราว 2 นาที) เพื่อไม่ให้ดูเป็นการส่งถี่
  • ทำให้เร็วขึ้น — ใช้ API แทนเว็บ และเลือกตัวเข้ารหัสการ์ดจอ

ทำหลายงานพร้อมกันได้ไหม

ใส่งานเข้าคิวได้ไม่จำกัด แอปทำตาม จำนวนงานที่ทำพร้อมกัน (ค่าเริ่มต้น 1) ถ้าใช้ API เพิ่มเป็น 2–4 ได้ ถ้าใช้ผ่านเว็บ แต่ละเว็บยังทำทีละคำขออยู่ดี

ปิดแอประหว่างทำงานได้ไหม

ได้ งานที่ค้างจะเริ่มขั้นตอนที่ค้างอยู่ใหม่เมื่อเปิดแอปครั้งถัดไป ภาพและคลิปที่เสร็จแล้วเก็บไว้ แต่การโพสต์ที่ตั้งเวลาด้วยแอปจะไม่ทำงานตอนแอปปิด

ใช้ Chrome หลายโปรไฟล์ / หลายบัญชีได้ไหม

ได้ จับคู่ส่วนขยายในแต่ละโปรไฟล์ แล้วกำหนดว่าเว็บไหนใช้โปรไฟล์ไหน ดู เชื่อมเบราว์เซอร์และบัญชี

ใช้บน Mac ได้ไหม

ตอนนี้มีตัวติดตั้งสำหรับ Windows เท่านั้น

แก้คำสั่งที่ส่งให้ AI ได้ไหม

ได้ทุกข้อที่ ตั้งค่า → พรอมต์ระบบ และกำหนดต่องานได้ในช่อง “คำสั่งเพิ่มเติมถึง AI”

ตั้งค่าเริ่มต้นของหน้าสร้างงานให้เป็นแบบของฉันได้ไหม

ใช้ พรีเซ็ต บันทึกชุดค่าที่ใช้บ่อย ดู พื้นฐานหน้าสร้างงาน ส่วนค่ากลาง เช่น ซับ ลายน้ำ แฮชแท็ก ตั้งที่ ตั้งค่า
