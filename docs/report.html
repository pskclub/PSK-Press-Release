เริ่มต้น

หน้าแรก ติดตั้งและอัปเดต เชื่อมเบราว์เซอร์และบัญชี ตั้งค่าครั้งแรก คลิปแรกใน 10 นาที

สร้างงาน

พื้นฐานหน้าสร้างงาน การตกแต่งและส่งออก คลิปขายสินค้า คลิป AI ด้วย Google Flow เรื่องเล่า AI ข่าว พอดแคสต์ รีมิกซ์ & ขัดเกลา ชุดภาพสินค้า แม่แบบพรอมต์ ตัดต่อเอง

งาน

ตรวจฉาก (storyboard) คิวงานและบันทึก ผลงาน โพสต์

คลัง

สินค้า ตัวละคร เสียง & เพลง ชุดแบรนด์ คลังพรีเซ็ตชุมชนและแชร์การตั้งค่า

ระบบ

ตั้งค่าทั้งหมด พรอมต์ระบบ แก้ปัญหาที่พบบ่อย แจ้งปัญหาให้ผู้พัฒนา คำถามที่พบบ่อย ใช้อย่างรับผิดชอบ

ระบบ

แจ้งปัญหาให้ผู้พัฒนา

คัดลอกข้อมูลแจ้งปัญหาได้ในคลิกเดียวจากทุกจุดที่เจอปัญหา แอปตัดคีย์ API อีเมล และข้อมูลส่วนตัวออกให้ และไม่ส่งอะไรออกไปเอง

เจอปัญหา ให้ส่ง ข้อมูลแจ้งปัญหา ให้ผู้พัฒนา ในนั้นมีเวอร์ชันแอปและเครื่องมือ การตั้งค่าที่เกี่ยวข้อง และบันทึกการทำงาน (log) ล่าสุด ช่วยให้แก้ได้ตรงจุดโดยไม่ต้องถามกลับหลายรอบ

คัดลอกจากจุดที่เจอปัญหา

เจอปัญหาที่กดตรงไหนได้อะไรเพิ่ม
งานที่ล้มเหลว (คิวงาน → ไม่สำเร็จ)คัดลอกข้อมูลแจ้งปัญหา ใต้ข้อความผิดพลาดค่าที่ใช้สร้างงาน และบันทึกของงานนั้น
หน้าต่างบันทึกงานแจ้งปัญหา บนแถบเครื่องมือบันทึกของงาน
หน้าตรวจฉากแจ้งปัญหา มุมขวาบนบันทึกของงาน
โพสต์ที่ล้มเหลว (โพสต์ → คิวโพสต์)แจ้งปัญหา ท้ายแถวตัวเลือกโพสต์ และบันทึกการโพสต์
ส่วนขยาย / การเชื่อมต่อแจ้งปัญหาการเชื่อมต่อ หน้าเชื่อมต่อบันทึกการเชื่อมต่อส่วนขยาย
ข้อความแจ้งข้อผิดพลาดมุมจอคัดลอกรายละเอียด ในข้อความนั้นข้อความผิดพลาด
ปัญหาทั่วไปตั้งค่า → เกี่ยวกับ → แจ้งปัญหา…—

กดแล้วข้อมูลจะถูกคัดลอกทันที วางส่งในแชตหรืออีเมลได้เลย ในข้อความแจ้งที่ขึ้นมามีปุ่ม ดู/เพิ่มรายละเอียด ถ้าอยากเล่าเพิ่มหรือตรวจก่อนส่ง

หน้าต่างแจ้งปัญหา

  1. เล่าสั้น ๆ ว่าเกิดอะไรขึ้น เช่น กดอะไร คาดว่าจะเห็นอะไร แต่เห็นอะไรแทน
  2. ตรวจ รายงานที่จะส่ง แก้หรือลบส่วนไหนก็ได้
  3. เลือก คัดลอก · บันทึกเป็นไฟล์… · หรือ เปิดหน้าแจ้งปัญหาบน GitHub (แอปคัดลอกรายงานเต็มไว้ให้ วาง Ctrl+V ในหน้านั้น)
ข้อมูลส่วนตัวรายงานไม่มีคีย์ API (มีแค่ว่าตั้งไว้หรือไม่) และแอปตัดอีเมล โฟลเดอร์ส่วนตัว รหัสแชต Telegram และรหัสโปรไฟล์ Chrome ออกให้ แอปไม่ส่งข้อมูลการใช้งานออกไป — คุณเลือกเองว่าจะส่งอะไรให้ใคร

หน้าไหนแสดงผลไม่ได้

ถ้าหน้าใดมีปัญหา แอปจะแสดงข้อความแทนจอว่าง พร้อมปุ่ม ลองเปิดหน้านี้อีกครั้ง คัดลอกข้อมูลแจ้งปัญหา และ โหลดแอปใหม่ งานในคิวยังทำต่อตามปกติ

บันทึกการทำงานของแอป

แอปเก็บบันทึกการทำงานไว้ในเครื่อง (สูงสุดราว 10 MB แล้ววนทับ) เปิดโฟลเดอร์ได้ที่ ตั้งค่า → เกี่ยวกับ → เปิดโฟลเดอร์บันทึก (log)
