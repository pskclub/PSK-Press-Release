# คลังพรีเซ็ตชุมชน PSK Press

ชุดการตั้งค่าและพรีเซ็ตที่ผู้ใช้ PSK Press แบ่งปันกัน เช่น สไตล์ซับไตเติล พรีเซ็ตเรื่องเล่า
หรือพรีเซ็ตคลิปขายสินค้า — เปิดในแอปได้ที่เมนู **คลังพรีเซ็ตชุมชน**

## ใช้งานอย่างไร

1. ในแอป เปิดเมนู **คลังพรีเซ็ตชุมชน** แล้วกด **นำเข้า** ที่ชุดที่ชอบ
2. แอปจะเปิดหน้า **ตั้งค่า → แก้แบบ JSON** ให้ดูก่อนว่าจะเปลี่ยนอะไรบ้าง
   และตรวจว่าเข้ากับเวอร์ชันของแอปหรือไม่
3. กด **นำไปใช้** เมื่อพอใจ — ไม่มีอะไรเปลี่ยนจนกว่าจะกดยืนยัน

นำเข้าจากลิงก์ก็ได้: ลิงก์แบบ `psk-press://import?url=<ลิงก์ไฟล์ .json แบบ https>`
จะเปิดแอปแล้วโหลดชุดนั้นมาให้ตรวจเหมือนกัน

ชุดการตั้งค่าไม่มีคีย์ API และ (เมื่อส่งออกแบบแจกจ่าย) ไม่มีค่าที่เป็นของเครื่องใดเครื่องหนึ่ง
เช่น ตำแหน่งไฟล์ โปรไฟล์ Chrome หรือแชต Telegram

## โครงสร้างโฟลเดอร์

```
community/
  index.json          รายการทั้งหมดที่แอปแสดง
  bundles/<id>.json   ไฟล์ชุดการตั้งค่า (ส่งออกจากแอป)
  previews/<id>.jpg   ภาพตัวอย่าง (ไม่บังคับ)
```

### รูปแบบ `index.json`

```json
{
  "format": "psk-press-community",
  "version": 1,
  "entries": [
    {
      "id": "subtitle-bold-pop",
      "name": "ซับตัวหนาเด้งทีละคำ",
      "description": "อธิบายสั้น ๆ ว่าได้อะไร เหมาะกับงานแบบไหน",
      "author": "ชื่อผู้สร้าง",
      "tags": ["ซับไตเติล", "คลิปสั้น"],
      "contains": { "settings": ["subtitle"], "presets": [] },
      "minAppVersion": "0.3.0",
      "bundle": "bundles/subtitle-bold-pop.json",
      "preview": "previews/subtitle-bold-pop.jpg"
    }
  ]
}
```

| ช่อง | ความหมาย |
|---|---|
| `id` | ชื่อไฟล์ ใช้ a-z 0-9 และ `-` เท่านั้น ห้ามซ้ำ |
| `name`, `description`, `author`, `tags` | แสดงในแอป |
| `contains.settings` | ส่วนการตั้งค่าที่ชุดนี้เปลี่ยน เช่น `subtitle`, `media`, `llm` (ตรงกับชื่อส่วนในหน้า แก้แบบ JSON) |
| `contains.presets` | หน้าที่มีพรีเซ็ตในชุดนี้ เช่น `story`, `product`, `news`, `podcast`, `remix`, `polish`, `imageset` |
| `minAppVersion` | เวอร์ชันแอปขั้นต่ำที่ใช้ชุดนี้ได้ |
| `bundle` | ไฟล์ชุดการตั้งค่า (อ้างอิงจากตำแหน่งของ index.json หรือเป็นลิงก์ https เต็ม) |
| `preview` | ภาพหรือวิดีโอตัวอย่าง (ไม่บังคับ) |

อยากส่งชุดของคุณเข้าคลัง อ่าน [CONTRIBUTING.md](CONTRIBUTING.md)
