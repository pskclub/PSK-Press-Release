# ส่งพรีเซ็ตของคุณเข้าคลังชุมชน

ขอบคุณที่แบ่งปัน! ทำตามนี้เพื่อให้ชุดของคุณนำเข้าได้เรียบร้อยบนเครื่องคนอื่น

## 1. ส่งออกจากแอปแบบแจกจ่าย

1. เปิด **ตั้งค่า → แก้แบบ JSON** แล้วกด **ส่งออกไฟล์…**
2. เลือกเฉพาะส่วนที่ต้องการแบ่งปัน (เช่น แค่ *ซับไตเติล* หรือแค่พรีเซ็ตหน้า *เรื่องเล่า AI*)
3. เปิด **ตัดค่าเฉพาะเครื่องออก** ไว้ (เปิดอยู่แล้วโดยค่าเริ่มต้น) — จะตัดตำแหน่งไฟล์
   โปรไฟล์ Chrome และแชต Telegram ออกให้
4. ใส่ชื่อชุด คำอธิบาย ชื่อผู้สร้าง และแท็ก แล้วบันทึกไฟล์

ถ้าแอปเตือนว่าพรีเซ็ต **อ้างถึงไฟล์ในเครื่อง** (เช่น เพลงหรือรูปสินค้าในเครื่องคุณ)
ให้เอาค่านั้นออกจากพรีเซ็ตก่อน เพราะเครื่องอื่นไม่มีไฟล์นั้น

## 2. เพิ่มเข้า repo ผ่าน Pull Request

1. Fork `pskclub/PSK-Press-Release`
2. วางไฟล์ที่ `community/bundles/<id>.json` — `<id>` ใช้ a-z 0-9 และ `-` เช่น `story-horror-short`
3. (ไม่บังคับ) ภาพตัวอย่างที่ `community/previews/<id>.jpg` ขนาดไม่เกิน 300 KB
4. เพิ่มรายการใน `community/index.json` ตามรูปแบบใน [README.md](README.md)
   ให้ `contains` ตรงกับสิ่งที่อยู่ในไฟล์จริง
5. เปิด Pull Request บอกสั้น ๆ ว่าชุดนี้ทำอะไร และทดสอบกับแอปเวอร์ชันไหน

ก่อนส่ง ลองนำเข้าไฟล์ของตัวเองในแอป (**แก้แบบ JSON → นำเข้าไฟล์…**)
ต้องขึ้น **เข้ากับเวอร์ชันนี้** โดยไม่มีข้อผิดพลาด

## กติกา

- **ห้ามมีข้อมูลส่วนตัว**: คีย์ API (แอปไม่ใส่ให้อยู่แล้ว) อีเมล เบอร์โทร ชื่อบัญชี ตำแหน่งไฟล์ในเครื่อง
- **ใช้เฉพาะเนื้อหาที่คุณมีสิทธิ์**: ข้อความในพรอมต์ ภาพตัวอย่าง ชื่อสินค้า/แบรนด์
- **ตั้งชื่อและคำอธิบายให้ตรงกับสิ่งที่ได้** ไม่โฆษณาเกินจริง
- ชุดที่ทำให้แอปทำงานผิดปกติ หรือขัดกับเงื่อนไขของแพลตฟอร์ม/ผู้ให้บริการ AI จะไม่ถูกรับ
- การส่งเข้าคลังถือว่ายินยอมให้ผู้ใช้คนอื่นนำไปใช้และดัดแปลงได้
