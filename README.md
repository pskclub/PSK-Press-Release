# PSK Press — ดาวน์โหลด (Downloads)

To install PSK Press for Windows:
1. Go to [Releases](https://github.com/pskclub/PSK-Press-Release/releases/latest).
2. Download the file that ends in `-setup.exe`.

The installed app checks for new versions on its own and offers to update.

This repo holds only the installers and the update file (`latest.json`). It has no source code.
