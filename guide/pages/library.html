title: ผลงาน desc: วิดีโอและชุดภาพที่สร้างเสร็จทั้งหมด — ค้นหา ดู แก้แคปชัน โพสต์ สร้างซ้ำ และกู้คืนจากถังขยะ หน้า ผลงาน

ค้นหาและกรอง

  • ค้นหา — ชื่อหรือแคปชัน
  • ประเภท — เรื่องเล่า, คลิปสินค้า, ข่าว, พอดแคสต์, รีมิกซ์, ขัดเกลา, ชุดภาพ
  • วันที่ — ทุกวัน / วันนี้ / 7 วัน / 30 วัน
  • สถานะโพสต์ — ยังไม่โพสต์ / โพสต์แล้ว

[[เปิดโฟลเดอร์ผลงาน]] มุมขวาบนเปิดโฟลเดอร์ใน File Explorer

เลือกหลายรายการ

ชี้ที่การ์ดแล้วติ๊กช่องเลือก แถบด้านบนจะมี [[โพสต์]] (ไปหน้าโพสต์พร้อมรายการที่เลือก) [[ลบ]] (ย้ายไปถังขยะ กดเลิกทำได้) และ [[ยกเลิก]]

รายละเอียดงาน

คลิกการ์ดเพื่อเปิด:

  • เล่นวิดีโอ หรือดูภาพทั้งชุด และเปลี่ยนชื่อได้
  • แคปชัน — แก้ได้ (บันทึกเมื่อคลิกออก) [[คัดลอก]] หรือ [[เขียนใหม่]] ให้ AI เขียนแคปชันใหม่
  • ประวัติการโพสต์ — โพสต์ไปที่ไหน เมื่อไร
  • ค่าใช้จ่ายโดยประมาณ — แยกตามบริการ AI ที่งานนั้นใช้ (เขียนบท ภาพ เสียง คลิป) คิดจากราคาใน ตั้งค่า → ค่าใช้จ่าย
  • ปุ่ม [[โพสต์]] [[เปิดโฟลเดอร์]] [[สร้างซ้ำ]] (สร้างงานใหม่ด้วยค่าเดิม) [[เบื้องหลัง]] [[บันทึก]] (ดูบันทึกงาน) [[ลบ]]
  • ไฟล์ประกอบ — ภาพฉาก คลิป เสียง ของงานนั้น

เบื้องหลัง: ผลงานนี้สร้างมาอย่างไร

หน้าต่าง เบื้องหลัง แท็บขั้นตอนและพรอมต์

[[เบื้องหลัง]] ในรายละเอียดงาน (หรือไอคอนเดียวกันใน คิวงาน) เปิดทุกอย่างที่ใช้สร้างผลงานชิ้นนั้น มี 3 แท็บ:

  • ขั้นตอนและพรอมต์ — ทุกครั้งที่เรียก AI เรียงตามลำดับ แยกตามขั้น (วางบท ภาพ วิดีโอ เสียงพากย์ ถอดเสียง) กดที่ขั้นเพื่อดูบริการ โมเดล ค่าที่ใช้ (สัดส่วนภาพ โมเดลคลิป ความละเอียด จำนวนรูปอ้างอิง) System prompt, Prompt, คำตอบของ AI และภาพหรือคลิปที่ได้ ขั้นที่ไม่สำเร็จมีกรอบแดงพร้อมสาเหตุ ทุกกล่องกดคัดลอกได้
  • Storyboard — ชื่อเรื่อง hook พาดหัว แคปชัน แล้วแต่ละฉาก (ภาพ คลิป บทพูด prompt ภาพ prompt การเคลื่อนไหว) หรือแต่ละแผ่นสตอรี่บอร์ดพร้อมทุกช็อต
  • การตั้งค่า — AI ที่ใช้จริง ในแต่ละงาน และค่าทุกตัวที่ใช้สร้างงานนี้ (สินค้า พรีเซนเตอร์ คลิป งานตัดต่อ) [[คัดลอก JSON]] ได้
  • JSON — ทุกอย่างข้างบนรวมเป็นเอกสาร JSON ชิ้นเดียว มีสีแยกชื่อและค่า พรอมต์หรือคำตอบของ AI ที่เป็น JSON อยู่แล้วจะเก็บเป็น JSON (ไม่ใช่ข้อความในเครื่องหมายคำพูด)

ปุ่ม [[คัดลอกเป็น JSON]] และ [[บันทึกไฟล์ .json]] ด้านบนส่งออกเบื้องหลังทั้งหมด (ค่าที่ใช้ บริการที่ใช้ ทุกขั้นพร้อม System prompt, Prompt, คำตอบของ AI, ข้อผิดพลาด, ไฟล์ที่ได้ และ storyboard) ไปวิเคราะห์หรือปรับจูนต่อ เช่น เทียบพรอมต์ระหว่างงานที่ออกมาดีกับไม่ดี หรือส่งให้ AI ช่วยปรับพรอมต์ระบบ (ดู พรอมต์ระบบ)

งานเก่าที่ยังไม่มีบันทึกแบบละเอียดจะไม่มีรายการขั้นตอนและ storyboard แต่ยังดูแท็บการตั้งค่าได้

ภาพในชุดภาพ ภาพฉาก และแผ่นสตอรี่บอร์ด คลิกเพื่อดูรูปเต็มได้ (กด Esc หรือคลิกนอกรูปเพื่อปิด มีปุ่มเปิดในโฟลเดอร์)

ถังขยะ

แท็บ ถังขยะ เก็บงานที่ลบ กด [[กู้คืน]] เพื่อเอากลับ หรือ [[ลบถาวรทั้งหมด]] (ย้อนกลับไม่ได้ แอปจะถามก่อน)
