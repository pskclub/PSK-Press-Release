title: แก้ปัญหาที่พบบ่อย desc: ข้อความผิดพลาดที่เจอบ่อย ความหมาย และวิธีแก้ — เรียงตามส่วนของแอป

เมื่องานล้มเหลว แอปจะแสดงเหตุผลเป็นภาษาไทยในคิวงาน พร้อมลิงก์ไปหน้าที่แก้ได้ รายละเอียดทางเทคนิคอยู่ใน บันทึกของงาน (คิวงาน → [[ดูบันทึก]]) หลังแก้สาเหตุแล้ว กด [[ลองใหม่]]

ส่วนขยายและ Chrome

“ส่วนขยายเบราว์เซอร์ยังไม่ได้เชื่อมต่อ”

  • เปิด Chrome โปรไฟล์ที่ติดตั้งส่วนขยายไว้ ส่วนขยายจะเชื่อมเองภายในไม่กี่วินาที
  • ยังไม่ได้? ที่ chrome://extensions ตรวจว่า PSK Press Bridge เปิดอยู่ แล้วกดรีโหลด (↻)
  • หลังอัปเดตแอป ต้องรีโหลดส่วนขยาย 1 ครั้งเสมอ
  • ยังไม่ได้อีก: กดไอคอนส่วนขยาย → [[เชื่อมต่อ]] ใหม่ หรือใช้รหัสจับคู่ใน หน้าเชื่อมต่อ

“ยังไม่ได้ล็อกอิน …”

ล็อกอินเว็บนั้นในแท็บที่แอปเปิดไว้ แล้วกด [[ลองใหม่]] ถ้าใช้หลายโปรไฟล์ ตรวจว่าเว็บนั้นกำหนดให้ใช้โปรไฟล์ที่ล็อกอินอยู่ (เชื่อมต่อ → ใช้โปรไฟล์ไหนกับเว็บไหน)

“… ขอให้ยืนยันว่าเป็นมนุษย์”

เว็บขอ captcha แอปไม่แก้ captcha ให้ แอปจะสลับไปแท็บนั้นให้ ทำขั้นตอนยืนยันเองในแท็บ แล้วกด [[ลองใหม่]]

“… แจ้งว่าใช้งานถึงขีดจำกัดแล้ว”

โควตาของบัญชีเว็บหมด รอให้โควตารีเซ็ต อัปเกรดแพ็กเกจ หรือเปลี่ยนไปใช้ผู้ให้บริการอื่น (เช่น ใช้คีย์ API) แอปจะไม่สลับบัญชีหนีโควตาให้

“ไม่พบปุ่ม… ในหน้า …” (เช่น ไม่พบปุ่มแนบไฟล์)

หน้าเว็บอาจเปลี่ยนหน้าตา ข้อความจะบอกชื่อปุ่มที่แอปเห็นในหน้านั้น

  1. รีโหลดแท็บแล้วลองใหม่
  2. ถ้ายังพบซ้ำ ตรวจหาอัปเดตแอป (ตั้งค่า → เกี่ยวกับ) แล้วรีโหลดส่วนขยาย

งานค้างนานตอนรอคำตอบจาก Gemini/ChatGPT

  • แท็บที่อยู่ในหน้าต่าง Chrome ซึ่งถูกบังหรือย่อไว้ อาจหยุดอัปเดต แอปจะโหลดหน้าใหม่แล้วอ่านคำตอบให้เองอัตโนมัติ
  • ถ้าเกิดบ่อย ให้เปิดหน้าต่าง Chrome ไว้ อย่าย่อ
  • ถ้าคุณปิดหน้าต่าง Chrome หมดทุกหน้าต่าง แอปจะเปิดหน้าต่างใหม่ให้เอง

AI เขียนบทและวาดภาพ

“Gemini แจ้งข้อผิดพลาด: …” หรือ Gemini ตอบว่า “I seem to be encountering an error”

ระบบของ Gemini ขัดข้องชั่วคราว แอปจะรอ 8 วินาทีแล้วลองใหม่ในแชตใหม่เอง แล้วรอ 16 วินาทีก่อนลองอีกครั้ง ถ้ายังไม่ได้ งานจะหยุด ให้รอสักพักแล้วกด [[ลองใหม่]]

“AI ไม่ได้เขียนฉากมาให้” / “AI ตอบรูปแบบไม่ถูกต้อง”

คำตอบของ AI ไม่มีบทที่อ่านได้ แอปถามซ้ำให้แล้ว 3 ครั้ง ลองวิธีเหล่านี้:

  • กด [[ลองใหม่]]
  • ปรับหัวข้อให้ชัดขึ้น
  • ลดความยาวงาน
  • ถ้าเพิ่งแก้พรอมต์ ลองคืนค่าเริ่มต้นใน พรอมต์ระบบ

“… ปฏิเสธคำขอ”

AI ไม่ยอมทำตามคำขอเพราะนโยบายเนื้อหา ปรับหัวข้อหรือคำบรรยายภาพให้เลี่ยงเนื้อหาอ่อนไหว คนมีชื่อเสียง หรือแบรนด์ของผู้อื่น

“คีย์ของ … ใช้ไม่ได้หรือไม่มีสิทธิ์”

ตรวจคีย์ที่ ตั้งค่า → คีย์ API ด้วยปุ่ม [[ตรวจ]] คีย์อาจหมดอายุ ถูกลบ หรือบัญชียังไม่เปิดใช้บริการนั้น

“… เลิกให้บริการโมเดลนี้แล้ว หรือบัญชีนี้ใช้ไม่ได้”

ผู้ให้บริการปิดโมเดลที่เลือกไว้ หรือบัญชีของคุณยังใช้โมเดลนั้นไม่ได้ ไปที่ ตั้งค่า → โมเดล AI กดปุ่มโหลดรายชื่อโมเดลใหม่ แล้วเลือกโมเดลอื่น

“… แจ้งว่าใช้งานถี่หรือโควตาหมด” / “ขัดข้องชั่วคราว”

แอปรอและลองใหม่ให้เองอยู่แล้ว ถ้ายังไม่ได้ รอสักครู่แล้วกดลองใหม่ หรือตรวจยอดเงินในบัญชีผู้ให้บริการ

คลิป AI (Google Flow)

Flow ปฏิเสธ: “อาจละเมิดนโยบายเกี่ยวกับบุคคลที่มีชื่อเสียง”

เกิดบ่อยเมื่อคลิปมีหน้าคนสมจริง โดยเฉพาะกับ Omni 1.1 Flash แอปลองให้เอง 3 รอบแล้ว (ดู เมื่อคลิปสร้างไม่สำเร็จ) ถ้ายังไม่ผ่าน ลองวิธีเหล่านี้:

  1. เปลี่ยนโมเดลเป็น Veo 3.1 - Fast
  2. ใช้รูปนายแบบที่ไม่ใช่คนดัง และคุณมีสิทธิ์ใช้
  3. เปลี่ยนชื่อตัวละครที่อาจซ้ำคนจริง
  4. ในหน้าตรวจฉาก แก้คำบรรยายภาพให้เน้นสินค้าหรือมือแทนใบหน้า แล้วกด [[สร้างคลิปใหม่]]

Flow ไม่หักเครดิตเมื่อปฏิเสธ

งานหยุดที่ “รอตรวจฉาก” เพราะคลิปไม่สำเร็จ

เปิด [[เปิดตรวจฉาก]] ฉากหรือแผ่นที่มีปัญหาจะมีป้าย คลิปไม่สำเร็จ พร้อมเหตุผล แก้แล้วกด [[สร้างคลิปใหม่]] หรือเปลี่ยนชนิดฉากเป็นภาพนิ่ง แล้ว [[อนุมัติและเรนเดอร์]] คลิปที่ทำสำเร็จแล้วยังอยู่ ไม่เสียเครดิตซ้ำ

“ติดต่อ Google Flow ไม่ได้ในงานนี้”

ตรวจว่าส่วนขยายเชื่อมอยู่และล็อกอิน Google Flow ใน Chrome แล้ว ลองเปิด labs.google/flow เองในแท็บ

Flow ถามเรื่องสิทธิ์ใช้รูปทุกครั้ง

กดยืนยันในแท็บ Flow เอง หรือเปิด ยืนยันสิทธิ์ใช้รูปภาพใน Google Flow ให้อัตโนมัติ ที่ ตั้งค่า → โมเดล AI → วิดีโอ AI (เฉพาะเมื่อคุณมีสิทธิ์ใช้ทุกรูปจริง)

เครดิต Flow หมด

งานหยุดทันทีโดยไม่ลองซ้ำ เติมเครดิตหรือรอรอบใหม่ แล้วกด [[ลองใหม่]] คลิปที่ทำแล้วยังอยู่

บทพูดในคลิปถูกตัดหรือพูดเร็วเกิน

บทยาวเกินเวลาคลิป แอปขอให้ AI ย่อบทที่ยาวเกินให้แล้ว 1 ครั้ง ตรวจในหน้าตรวจฉากว่าบทต่อแผ่นอยู่ราว 58–72 ตัวอักษร (คลิป 8 วินาที) หรือเลือก 3 ช็อตต่อแผ่น

เรนเดอร์และเครื่องมือ

“FFmpeg (ตัวประกอบวิดีโอ) ใช้ไม่ได้”

ไปที่ ตั้งค่า → โฟลเดอร์และเครื่องมือ กด [[ตรวจใหม่]] ถ้ายังไม่ได้ ติดตั้งแอปทับอีกครั้ง โปรแกรมป้องกันไวรัสบางตัวอาจกักไฟล์ ffmpeg.exe ไว้ ให้ตรวจรายการกักกันของโปรแกรมด้วย

ดาวน์โหลดคลิปจากลิงก์ไม่ได้ (รีมิกซ์)

กด [[อัปเดต]] ที่ yt-dlp ใน ตั้งค่า → โฟลเดอร์และเครื่องมือ เว็บวิดีโอเปลี่ยนระบบบ่อย yt-dlp จึงต้องอัปเดตตาม

เรนเดอร์ช้า

  • เลือกตัวเข้ารหัสการ์ดจอที่ ตั้งค่า → การเรนเดอร์
  • ลดความละเอียดเป็น 1080p
  • ใช้คุณภาพ “มาตรฐาน”

ซับไม่ตรงกับเสียง

  • ขัดเกลาคลิปพูด — ปรับ เลื่อนเวลาซับ
  • คลิป AI ที่คนพูดเอง — ซับจะแม่นเมื่อมีคีย์ OpenAI ให้ถอดเสียงจริง ถ้าไม่มีคีย์ แอปใช้บทที่วางไว้แทน เวลาจึงอาจคลาดเล็กน้อย

โพสต์

โพสต์ล้มเหลว

ดูเหตุผลใน โพสต์ → คิวโพสต์ สาเหตุที่พบบ่อย:

  • ยังไม่ล็อกอินบัญชี
  • แพลตฟอร์มเปลี่ยนหน้าตา
  • ตัวเลือกไม่ตรงกับบัญชี (เช่น ติดตะกร้าในบัญชีที่ไม่มี TikTok Shop)

กด [[ลองใหม่]] หรือโพสต์เองจากแท็บที่แอปเปิดไว้ แนะนำให้ใช้โหมด “เตรียมไว้ให้ตรวจ” จนกว่าจะมั่นใจ

โพสต์ตั้งเวลาไม่ออก

การตั้งเวลาด้วยแอป แอปต้องเปิดอยู่ตอนถึงเวลา ถ้าจะปิดเครื่อง ให้เปิด ตั้งเวลาไว้บนแพลตฟอร์มเลย

ติดตั้งและอัปเดต

Windows ไม่ให้เปิดตัวติดตั้ง

กด ข้อมูลเพิ่มเติม → เรียกใช้ต่อไป ดู ติดตั้งและอัปเดต

“ตรวจหาอัปเดตไม่ได้”

ตรวจอินเทอร์เน็ต แล้วลองใหม่ หรือดาวน์โหลดตัวติดตั้งล่าสุดจาก หน้า Releases แล้วติดตั้งทับ ข้อมูลและการตั้งค่าไม่หาย

ยังแก้ไม่ได้?

กด [[คัดลอกข้อมูลแจ้งปัญหา]] ที่งานหรือโพสต์ที่มีปัญหา แล้ววางส่งให้ผู้พัฒนา — ได้เวอร์ชัน การตั้งค่าที่เกี่ยวข้อง และบันทึกของงานในครั้งเดียว ตัดข้อมูลส่วนตัวออกให้แล้ว ดู แจ้งปัญหาให้ผู้พัฒนา · ถ้าโพสต์ไม่ได้ ลอง ตรวจความพร้อมการโพสต์ ก่อน

หรือเปิดบันทึกของงานแล้วกด [[ส่งออก]] (.txt) ส่งไฟล์นั้นพร้อมบอกว่าทำอะไรอยู่
